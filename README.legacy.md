
# Economic Research Data Pipeline

A Python-based data engineering project designed to help students and researchers retrieve, process, and analyze economic data.

## Project Objectives

- Retrieve economic indicators from the World Bank API.
- Clean and organize economic datasets.
- Merge multiple indicators into research-ready datasets.
- Export datasets in CSV and Excel formats.
- Build a foundation for a research data platform.

## Technologies

- Python
- Pandas
- Requests
- Jupyter Notebook

## Data Source

World Bank Open Data
https://data.worldbank.org/
